Foodie Blog

Features:
Clean and user-friendly UI
Responsive layout
Easy navigation
Simple and attractive design for reading food posts

Technologies Used:
HTML
CSS
JavaScript

How to Use:
Clone the repository
Open the project folder
Open index.html in any browser
